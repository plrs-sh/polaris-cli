# Polaris CLI releases

Official macOS and Linux release artifacts for the Polaris CLI.

Install the latest stable release:

```sh
curl --proto '=https' --tlsv1.2 -fsSL \
  https://github.com/plrs-sh/polaris-cli/releases/latest/download/install.sh | sh
```

Every release includes SHA-256 checksums, a strict update manifest, and public
Sigstore bundles. The implementation source remains in the private Polaris
repository.
